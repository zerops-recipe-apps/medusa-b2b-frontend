# Medusa B2B Next.js storefront

Next.js 15 B2B storefront for [zerops-recipe-apps/medusa-b2b](https://github.com/zerops-recipe-apps/medusa-b2b). Deploy with `zeropsSetup: dev` or `prod` from [`zeropsio/recipes/medusa-b2b`](https://github.com/zeropsio/recipes/tree/main/medusa-b2b).

Local: `yarn dev` on port 8000 against your Medusa `API_URL` and publishable key.
