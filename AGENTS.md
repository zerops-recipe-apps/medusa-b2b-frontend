# medusa-b2b-nextstore

Next.js 15 B2B storefront (Yarn 3 Berry). Pairs with [medusa-b2b](https://github.com/zerops-recipe-apps/medusa-b2b).

- Zerops setups: `dev` (workspace, `deployFiles: ./`) and `prod`
- Port `8000`, readiness `/api/health`
- Project vault: `APP_URL`, `API_URL`, `CHANNEL_PUBLISHABLE_KEY`, `MEDUSA_HOST`, `RELOAD_SECRET`
